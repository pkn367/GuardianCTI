# Results — Evaluation & Benchmarks

## Purpose

Holds evaluation outputs comparing GuardianCTI against baseline/traditional CSPM approaches, and tracks model performance over the project timeline.

## Planned Contents

- **Model performance metrics** — precision/recall/F1 for anomaly detection, ranking quality (NDCG) for risk prioritization
- **Baseline comparison** — GuardianCTI vs. static rule-based CSPM tool on the same simulated environment
- **Detection latency** — time from misconfiguration/threat appearance to flagged finding
- **Case studies** — 2–3 walkthroughs of a detected finding, its threat-intel correlation, HIPAA mapping, and remediation suggestion
- **Screenshots/exports** from the `Frontend` dashboard demonstrating results
